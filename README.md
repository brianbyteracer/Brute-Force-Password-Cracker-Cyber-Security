Developed a Brute Force Password Security Testing Tool using Python as part of my cybersecurity learning journey.

This project focuses on understanding how password hashing and brute force techniques work in real-world authentication systems. The tool was built using Python and the built-in hashlib library to work with commonly used hashing algorithms such as MD5 and SHA-1.

In this project, encrypted passwords are stored in the form of hash values rather than plain text. The tool takes a target hash and compares it against hashes generated from words stored in a local text file (wordlist/dictionary). Each word from the text file is converted into its corresponding MD5 or SHA-1 hash using the hashlib library. If a generated hash matches the target hash, the original password is identified successfully.

Through this project, I gained practical knowledge of:
• Password hashing mechanisms
• MD5 and SHA-1 encryption concepts
• Dictionary-based brute force attacks
• File handling in Python
• Authentication and password security concepts
• Basics of ethical hacking and penetration testing

This project helped me strengthen my understanding of cybersecurity fundamentals and demonstrated how weak passwords can be vulnerable to brute force and dictionary attacks. It also improved my problem-solving and Python programming skills while exploring real-world security concepts in a controlled and educational environment.
